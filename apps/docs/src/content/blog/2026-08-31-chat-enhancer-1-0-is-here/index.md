Version 1.0.0 is here. Chat Enhancer has been stable for a while, and now the version number reflects that.

Over time, Chat Enhancer has found its shape: a focused set of tools that makes YouTube live chat easier to keep up with, follow, and take part in, without turning it into a different chat.

The features now feel like parts of the same product, and the everyday experience has already been dependable for a while. That is what 1.0 means.

## This is Chat Enhancer 1.0

- **Catch what would otherwise disappear:** Inbox collects mentions and watched keywords, with optional highlights, sounds, and tab alerts.
- **Keep conversations in reach:** Mention, Quote, recent messages, and Focus mode make it easier to follow people and replies.
- **Make chat feel more personal:** User and message bookmarks, frequent emojis, and chat themes keep the useful details close.
- **Write with less friction:** Message and draft translation, draft recovery, and Tab commands make joining in easier.

No single feature is the whole of Chat Enhancer. The useful part is having them together, right where the chat already is.

## A clearer idea of what belongs

Reaching 1.0 makes it easier to say what a Chat Enhancer feature should do. It should solve a real annoyance, feel at home inside YouTube, and stay quiet until it is useful.

That also gives the extension a useful boundary. Chat Enhancer is not trying to replace YouTube chat, cover it with controls, or turn every possible idea into a setting. New features should earn their place.

## Stable, not finished

The core has been stable for a while, but YouTube will not stand still. Chat Enhancer will keep being polished and adjusted along with it. Future updates can start from a better question than “what else can be added?”: “what would make the experience noticeably better?”

Lite mode and Playground still carry **Beta** labels. They are optional, off by default, and useful today, but they have more room to change than the rest of the extension.

## Available now

Chat Enhancer is now available for Chrome, Firefox, and Safari. The [install section](https://www.chatenhancer.com/#install) links to the current store version for each browser. The code and tagged 1.0 release packages are also on [GitHub](https://github.com/chatenhancer/youtube-chat-qol/releases/tag/v1.0.0).

Thanks for using Chat Enhancer in real chats and pointing out the details that still felt off. Version 1.0 is a marker that Chat Enhancer knows what it is now. The work from here is to keep it feeling that way. If something does not, [send a note](mailto:hello@chatenhancer.com).
