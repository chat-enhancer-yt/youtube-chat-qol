เวอร์ชัน 1.0.0 มาแล้ว Chat Enhancer มีความเสถียรมาระยะหนึ่ง และตอนนี้หมายเลขเวอร์ชันก็สะท้อนสิ่งนั้น

เมื่อเวลาผ่านไป Chat Enhancer พบรูปแบบที่ควรเป็น: ชุดเครื่องมือที่มุ่งช่วยให้ตามแชทสดของ YouTube ทัน ติดตามบทสนทนา และร่วมพูดคุยได้ง่ายขึ้น โดยไม่เปลี่ยนแชทให้กลายเป็นอย่างอื่น

ฟีเจอร์ต่าง ๆ ตอนนี้รู้สึกเป็นส่วนหนึ่งของผลิตภัณฑ์เดียวกัน และประสบการณ์ในชีวิตประจำวันก็น่าเชื่อถือมาระยะหนึ่งแล้ว นี่คือความหมายของ 1.0

## นี่คือ Chat Enhancer 1.0

- **เก็บสิ่งที่จะหายไป:** กล่องข้อความรวบรวมการกล่าวถึงและคีย์เวิร์ดที่ติดตาม พร้อมตัวเลือกไฮไลต์ เสียง และการแจ้งเตือนบนแท็บ
- **เก็บบทสนทนาไว้ใกล้มือ:** การกล่าวถึง การอ้างข้อความ ข้อความล่าสุด และโหมด Focus ช่วยให้ติดตามผู้คนและคำตอบได้ง่ายขึ้น
- **ทำให้แชทเป็นส่วนตัวมากขึ้น:** บุ๊กมาร์กผู้ใช้และข้อความ อีโมจิที่ใช้บ่อย และธีมแชทช่วยเก็บรายละเอียดที่มีประโยชน์ไว้ใกล้ตัว
- **เขียนได้ลื่นขึ้น:** การแปลข้อความและข้อความร่าง การกู้คืนข้อความร่าง และคำสั่ง Tab ช่วยให้ร่วมพูดคุยได้ง่ายขึ้น

ไม่มีฟีเจอร์ใดฟีเจอร์หนึ่งที่เป็น Chat Enhancer ทั้งหมด ประโยชน์คือการมีฟีเจอร์เหล่านี้อยู่ด้วยกัน ตรงที่แชทอยู่แล้ว

## เข้าใจชัดขึ้นว่าอะไรควรอยู่ในนี้

การมาถึง 1.0 ทำให้อธิบายได้ง่ายขึ้นว่าฟีเจอร์ของ Chat Enhancer ควรทำอะไร ฟีเจอร์นั้นควรแก้ปัญหาที่มีอยู่จริง ดูเป็นธรรมชาติใน YouTube และไม่รบกวนจนกว่าจะมีประโยชน์

สิ่งนี้ยังสร้างขอบเขตที่เหมาะสมให้ส่วนขยายด้วย Chat Enhancer ไม่ได้พยายามแทนที่แชทของ YouTube ปิดทับด้วยปุ่มควบคุม หรือเปลี่ยนทุกไอเดียให้เป็นการตั้งค่า ฟีเจอร์ใหม่ต้องมีเหตุผลที่คู่ควรกับพื้นที่ของมัน

## เสถียร แต่ยังไม่จบ

ส่วนหลักมีความเสถียรมาระยะหนึ่ง แต่ YouTube จะไม่หยุดเปลี่ยน Chat Enhancer จะยังได้รับการขัดเกลาและปรับตามไปด้วย การอัปเดตในอนาคตสามารถเริ่มจากคำถามที่ดีกว่า “เพิ่มอะไรได้อีก?” นั่นคือ “อะไรจะทำให้ประสบการณ์ดีขึ้นอย่างเห็นได้ชัด?”

โหมด Lite และ Playground ยังคงมีป้าย **Beta** ทั้งคู่เป็นตัวเลือก ปิดไว้โดยค่าเริ่มต้น และมีประโยชน์แล้วในวันนี้ แต่ยังเปลี่ยนแปลงได้มากกว่าส่วนอื่นของส่วนขยาย

## พร้อมใช้งานแล้ว

ตอนนี้ Chat Enhancer พร้อมใช้งานสำหรับ Chrome, Firefox และ Safari [ส่วนการติดตั้ง](https://www.chatenhancer.com/#install)จะพาไปยังเวอร์ชันปัจจุบันในร้านค้าของแต่ละเบราว์เซอร์ โค้ดและแพ็กเกจรุ่น 1.0 อย่างเป็นทางการมีอยู่บน [GitHub](https://github.com/chatenhancer/youtube-chat-qol/releases/tag/v1.0.0) เช่นกัน

ขอบคุณที่ใช้ Chat Enhancer ในแชทจริงและชี้ให้เห็นรายละเอียดที่ยังรู้สึกไม่ถูกต้อง เวอร์ชัน 1.0 คือเครื่องหมายว่า Chat Enhancer รู้แล้วว่าตัวเองคืออะไร งานต่อจากนี้คือรักษาความรู้สึกนั้นไว้ หากบางอย่างไม่เป็นเช่นนั้น [ส่งข้อความมาได้](mailto:hello@chatenhancer.com)
